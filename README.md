# BMI Calculator using Java Swing

A simple and user-friendly BMI Calculator developed using Java Swing and AWT.

## Features

- Calculate BMI using weight and height
- Supports multiple weight units: kg, g, lbs
- Supports multiple height units: m, cm, ft, inch
- Displays BMI value and category
- Shows Underweight, Normal Weight, Overweight, and Obese categories
- Displays ideal weight range
- Visual BMI progress indicator
- Input validation and warning messages
- Clear button to reset the calculator
- Clean and responsive GUI

## Technologies Used

- Java
- Java Swing
- Java AWT
- Event Handling

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `BMICalculator.java`.
3. Run the `main()` method.
4. Enter your weight and height.
5. Select the appropriate units.
6. Click **Calculate BMI**.

## BMI Formula

BMI = Weight (kg) / Height² (m)
